# Luna Flow Cycle Care

Luna Flow Cycle Care is a women's menstrual health tracking application designed to help users monitor their menstrual cycles, track symptoms, understand cycle patterns, and maintain better health awareness.

## Features (Planned)

- Period cycle tracking
- Symptom tracking
- Cycle history management
- Health reminders
- User-friendly interface

## Purpose

This project aims to combine healthcare awareness and technology to create a simple and helpful menstrual health management application.

## Technologies (Future)

- Flutter / Android Development
- Database Integration
- AI-based health insights
